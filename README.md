# RadioMdl

This is a Julia package focused on the simulation of radio observation, e.g. for
radio astronomy. See the `test/tuto_mdl_obs.ipynb` notebook for a tour of the
package.

To install it, simply add it in `pkg` mode as a dev package:

```julia
dev $PATH
```

with `$PATH` the path to the `RadioMdl.jl` repository.
